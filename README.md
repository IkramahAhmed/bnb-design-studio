# BnB Design Studio website

Two static websites for BnB Design Studio (Wylie, Texas).

- `website/` : scroll-driven 3D site (Three.js). Source is `website/js/main.js`; run `npm install` then `npm run build` to produce `website/js/app.js`.
- `website-classic/` : clean multi-page static site (Home, About, Services, Portfolio, Contact, Privacy). No build step.

Upload the contents of either folder to any static host.
